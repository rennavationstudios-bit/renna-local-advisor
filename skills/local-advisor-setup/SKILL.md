# Local Advisor setup

Read `../../SETUP.md` and the relevant source before implementation. This is a
source adaptation task; the exported runtime has deliberate placeholders and an
inert launch guard. The template config is not wired into the original runtime.

Discover actual workers, exact model identities, context/tools and resource
ownership from existing local setup. Preserve the selected Codex primary/effort,
model tuning, active applications, source files and existing services. Record only
nonsecret observations; keep endpoint values in ignored private local config and
credential values in an OS store or inherited environment, never in chat or Git.

Make a narrow, reviewable integration using existing supported Codex MCP tools.
Use current official docs for configuration syntax. Do not infer support from a
model name or install/start new model services without the user's authorization.

Preserve exact file ownership, original source hashes, shared-device reservations,
bounded deadlines and parent-owned tests. Treat local model output as untrusted
proposals. The primary integrates and verifies; it retains final acceptance and
external-action authority. Keep private-only/local-only/cloud-only choices intact.

Qualify read-only inference, isolated bounded proposals, parent apply and tests,
then optional parallel/tool/cancellation routes as described in SETUP.md. Report
what actually passed, the missing dependencies, and exact remaining blockers.
Remove the reference launch guard only after the selected route has been adapted,
reviewed and tested. Do not equate replacement of placeholders with acceptance.

Read [the shared Codex-credit report policy](../../docs/codex-credit-report.md).
Preserve its explicit-input, offline reporting contract and private output handling.
Keep Codex-credit estimates separate from API-dollar comparisons and measured
savings; state unavailable usage or unknown billing basis without guessing.
