# Image generation notes

These three graphics were generated for this repository using the connected Runway image tool after the built-in generator returned an authorization error. No CLI/API-key fallback, private screenshots, endpoints, credentials or source files were provided as image inputs. They are conceptual illustrations, not screenshots, benchmarks or deployment evidence. Final PNGs are preserved as returned by the service.

The same graphite/navy, cyan and amber visual direction was requested for all three. Each image was visually reviewed for accurate text, layout, role separation and absence of private details. `manifest.json` binds the exact reviewed bytes; the public verifier checks PNG structure and rejects text/EXIF metadata and trailing content.

The returned PNGs include C2PA content credentials identifying AI-generated media. That provenance is preserved. Its readable claim text was checked for credential/private-binding patterns without exposing claim values; no matches were found. No generation-service download URLs or authorization tokens are stored in this repository.
